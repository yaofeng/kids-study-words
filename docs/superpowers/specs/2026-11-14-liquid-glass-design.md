# 少儿背单词 — 液态玻璃视觉改版设计

日期：2026-11-14
状态：待确认
关联文档：[2026-11-13-study-words-design.md](2026-11-13-study-words-design.md)

## 1. 背景与意图

应用即将发布 1.0.0。功能已经稳定，但界面仍是「奶油底 + 黑描边 + 贴纸投影」的手绘风格，和现在移动端的视觉语言有距离。这次改版只动外观，不动功能，让应用看起来像一台新设备上的应用，同时保留给孩子用的活泼感。

核心诉求（已与用户确认）：

- **液态玻璃是主角**：半透明、边缘高光、背景被折射的质感来自 iOS 26 的 Liquid Glass。
- **卡通风做点缀**：猫头鹰吉祥物、表情图标、圆润字形保留，但不靠黑描边和硬阴影撑活泼。
- **主题色是卡通蓝**：选定「晴空蓝」方案，主色 `#3D9BF0`。
- **版本号升到 1.0.0**。

## 2. 目标与非目标

### 目标

- 全部现有页面（引导、登录、注册、查词、生词本、生词本详情、单词编辑、回忆选择、回忆、总结、记录、设置、错误页）统一到新的玻璃视觉。
- 建立一套可复用的玻璃样式变量与组件类，后续加页面不需要再手调阴影和透明度。
- 保留现有信息架构、文案、交互和 htmx 行为。
- 文字对比度、点击区域、焦点可见性达到可读性要求（8–12 岁用户）。
- 不支持 `backdrop-filter` 或开启「降低透明度」时，有清晰的降级外观。
- 版本号改为 `1.0.0`，`.version` 仍是唯一来源。

### 非目标

- 不改任何业务逻辑、路由、数据结构、表单字段。
- 不新增深色模式（当前应用没有，本次不引入）。
- 不引入前端框架、图标库或外部 CDN；继续使用内嵌 Nunito、htmx、Tailwind。
- 不重做页面布局，只调整表面质感、配色和必要的间距。
- 不改吉祥物造型和表情图标体系。

### 反目标

- 玻璃效果重到文字发虚、孩子看不清。
- 大面积高饱和蓝色压过单词本身。
- 低端平板上滚动掉帧。
- 只在新浏览器好看，旧设备上面板变成一坨半透明灰。

## 3. 约束

- Tailwind CSS 3.4.17，`web/static/app.css` 由 `make css` 生成并提交；构建后必须重新生成。
- 静态资源通过 `go:embed` 打进二进制，必须离线可用。
- 模板只使用组件类，主题色目前除 `layout.html` 的 `bg-cream` 外全部集中在 `web/static/input.css`，因此改动主要落在 CSS。
- 手机竖屏、平板横竖屏、桌面宽度（md 以上侧边导航）都要成立。
- 不引入运行时依赖，不增加需要用户配置的开关。

## 4. 方案

### 4.1 三版风格方向（用户已选 A）

- **A · 糖果玻璃（选定）**：玻璃面板 + 糖果色背景 + 无黑描边，卡通只留在吉祥物、表情和圆角字形里。玻璃是主角，活泼来自背景色。
- B · 果冻贴纸：玻璃表面 + 黑描边和贴纸投影。童趣最足，但描边把玻璃拉回「贴纸」，与「玻璃为主角」冲突。
- C · 白瓷玻璃：近乎纯白的厚玻璃。最克制，但孩子气最少。

### 4.2 三种蓝色处理（用户已选 1）

- **1 · 晴空蓝（选定）**：玻璃偏白、透度高，蓝色主要落在按钮和选中态。最接近 iOS 26，文字对比度最稳。
- 2 · 海盐蓝：蓝色进入玻璃本身，果冻感最强，但大面积蓝会压住内容。
- 3 · 星河蓝：蓝紫虹彩，最有魔法感，但偏离「学习工具」的气质。

## 5. 设计决定

### 5.1 色板

| Token | 值 | 用途 |
| --- | --- | --- |
| `blue` | `#3D9BF0` | 主色、选中态、进度、强调 |
| `blue-deep` | `#1F73D6` | 主按钮、重点文字、焦点环 |
| `blue-soft` | `#A9DCFF` | 徽章底、浅色描边 |
| `blue-text` | `#15529E` | 浅蓝底上的小号文字（徽章、选中标签） |
| `ink` | `#1E2D42` | 正文与标题 |
| `muted` | `#5B6B80` | 次要文字（在玻璃上仍需 ≥ 4.5:1） |
| `sky` | `#F2FAFF` | 页面底色 |
| `sun` | `#FFD966` | 星级、少量点缀 |
| `mint` | `#66D9C7` | 少量点缀，不承担状态含义 |
| `coral` | `#FF8A73` / `#A93A22` | 「不认识」、删除等负面状态；深色值专用于文字（对白约 6.3:1，对浅珊瑚底约 5.1:1） |
| `paper` | `#FFFFFF` | 不透明降级时的面板底色 |

「认识 / 不认识」继续用文字标签表达，不依赖颜色区分；蓝色代表认识，珊瑚色代表不认识。

### 5.2 玻璃配方

统一用装饰器级变量，不在页面里散写：

- 背景：两层半透明白色渐变（左上高光 → 中间透明 → 右下反光），叠在 `rgba(255,255,255,.2)` 上。
- 边框：`1px solid rgba(255,255,255,.75)`，不出现深色描边。
- 阴影：外阴影用蓝灰 `rgba(40,80,140,.16)`；内阴影在顶部和左侧各加一道白色高光，模拟折射边缘。
- 模糊：`backdrop-filter: blur(18px) saturate(180%)`，同时写 `-webkit-` 前缀。
- 圆角：卡片 20px，按钮/输入框 16px，导航胶囊 999px；保持圆润但不夸张。

### 5.3 性能取舍

`backdrop-filter` 很贵，页面里不能每个元素都开：

- **开模糊**：固定导航、顶部操作区、搜索/输入框、以及登录卡、回忆卡、总结卡这类单屏主卡。主按钮使用不透明蓝色实底，不参与模糊，以保证白字对比度。
- **不开模糊**：列表里的生词卡、记录行、设置分区。它们用 85–90% 白色渐变 + 同样的高光和边框，看起来仍是玻璃，但滚动成本低。
- 背景使用大半径 `radial-gradient` 绘制色块，不用大面积 `filter: blur()` 元素。
- 所有动效 150–200ms，且不持续播放；`prefers-reduced-motion` 时取消位移。

### 5.4 背景

- `body` 底色改为晴空渐变：`#F2FAFF → #E2F3FF → #EAF2FF`，带少量蓝、薄荷、阳光黄的大半径径向渐变。
- 现有云朵/星星 SVG 涂鸦保留，改成白色/浅蓝、低透明度，作为玻璃背后的小细节；不再使用深色。
- 桌面端固定侧栏后，背景仍铺满整页。

### 5.5 组件映射

| 组件 | 处理 |
| --- | --- |
| `.card` | 玻璃面板，去黑描边和贴纸阴影 |
| `.btn` | 玻璃胶囊按钮；按下轻微缩放，不用位移硬投影 |
| `.btn-primary` | 蓝色渐变实底（`#1F73D6 → #0F56AD`）+ 白字 + 内侧高光；实底不参与模糊 |
| `.btn-danger` / `.btn-unknown` | 珊瑚色玻璃底（珊瑚 26% + 白色高光）+ 深珊瑚字 `#A93A22`，不再用大块实色 |
| `.btn-known` | 深蓝 `#1F73D6` 实底 + 白字 |
| `.input` / `.textarea` / `.select` | 磨砂白底、浅蓝描边，聚焦时 `#1F73D6` 焦点环 |
| `.badge` | 半透明蓝/紫小胶囊，无黑描边；浅蓝底上的文字用 `blue-text` |
| `.app-nav` | 手机：悬浮玻璃胶囊（保留安全区）；桌面：玻璃侧栏 |
| `.nav-link.is-active` | 浅蓝胶囊 + 深蓝文字 |
| `.tab` / `.tab.is-active` | 玻璃胶囊 / 深蓝实底 + 白字 |
| `.record-row` | 无模糊的浅玻璃行 |
| `.alert-*` | 浅色玻璃底 + 深色文字 |
| `.star-*` | 去描边的扁平糖果星：实心阳光黄、空心浅蓝 `#A9DCFF`、半星黄蓝渐变 |
| `.owl` | 造型不变；描边从 `#3B3A36` 改为墨蓝 `#1E2D42`，与正文同色，不再用近黑色 |

Tailwind 配置里把 `teal` 系列改名 `blue` 系列、`teal-dark` 改名 `blue-deep`，避免语义错位；`cream` 改名 `sky`。由于模板里只有 `bg-cream` 一处，其余替换集中在 `input.css`。

### 5.6 可访问性

- 正文与 `muted` 在最终玻璃底上对比度 ≥ 4.5:1，大号标题 ≥ 3:1。
- 主按钮统一深蓝底 + 白字（`#1F73D6` 对白色约 4.7:1，渐变末端更深）。
- 焦点环保持 3px `#1F73D6`，偏移 2px。
- 触摸设备上所有可点控件命中区域不小于 44px。`.btn`、`.input` 保留现有 `min-h-[44px]`；`.tab`、`.btn-small`、`details summary` 在 `@media (pointer: coarse)` 下扩展命中区，桌面端保持紧凑，不改变页面层级。
- 「认识 / 不认识」同时有文字和颜色，不靠颜色单独传达。

### 5.7 降级

```css
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  /* 面板改为 94% 白色实底，边框改为 rgba(30,45,66,.12) */
}
@media (prefers-reduced-transparency: reduce) { /* 同上 */ }
```

降级后不追求玻璃感，但必须保持清晰、圆润、蓝色强调不变。

### 5.8 版本

- `.version` 从 `0.9.2` 改为 `1.0.0`；`version.go`、代码和静态资源都不写版本号。
- `version_test.go` 会扫描除少数目录外的全部文件，文档里出现版本号会误报。测试改为跳过 `docs/` 目录：文档可以记录发布号，代码和资源仍不得硬编码。

### 5.9 图标

导航、生词本徽章、计时器和设置按钮不再使用彩色 emoji，改为内嵌 SVG，和玻璃系统同一套语言：

- 24×24 画布、2px 圆头描边，颜色用 `currentColor`，随导航状态在 `muted` 与 `blue-text` 之间切换。
- 镜片、书页、日历面用当前色 8–16% 的淡填充；书签、日历圆点、卡片小星星用阳光黄 `#FFD966` 作卡通点缀。
- 六个模板：`icon_search`、`icon_book`、`icon_cards`、`icon_calendar`、`icon_settings`、`icon_timer`；导航 24px，徽章 15px，计时器 16px。
- 全部内嵌在 `partials.html`，不引外部图标文件或 CDN；SVG 标 `aria-hidden="true" focusable="false"`，语义由可见文字或 `aria-label` 提供。
- `TestIconsAreInlineSVG` 守住三件事：模板里不再出现 emoji、六个图标模板存在、导航恰好五个图标。

## 6. 留给实现者的判断

- 每处玻璃的具体透明度、渐变停靠点和高光强度，按本轮选定的「A · 糖果玻璃 / 1 · 晴空蓝」模拟稿微调。没有外部 Figma；模拟稿的 CSS 参数（`blur(18px) saturate(180%)`、白色高光内阴影、糖果色背景块）就是参考。
- 列表卡片是否在某些短列表页也开模糊（例如只有 1–2 张卡的登录页），按实际观感和滚动性能决定。
- 桌面侧栏宽度、内边距是否随新视觉微调，以不改变信息层级为准。
- 星星、云朵等装饰的最终透明度。
- 是否需要给猫头鹰加一条蓝色围巾之类的点缀：可选，不改变造型识别度。

## 7. 独立审阅后由我拍板的决定

文档初稿请一位独立实现者审阅，以下问题由我代替「必须问用户」处理。如果哪条你不认同，直接说，我改文档再动手：

1. **版本号测试与文档冲突**：`version_test.go` 会扫描 Markdown，设计文档里的版本号会触发失败。决定让测试跳过 `docs/`：文档可以记录发布号，代码与静态资源仍不得硬编码。
2. **主按钮不做玻璃模糊**：实底蓝渐变 + 白字，对比度稳定。模糊只留给导航、输入框和单屏主卡。
3. **浅蓝底上的小字改用更深的蓝**：新增 `blue-text #15529E`，避免 `blue #3D9BF0` 上的小字对比度不足；选中标签、认识按钮、主按钮统一用 `blue-deep` 而不是亮蓝。
4. **负面状态文字加深**：`coral-dark` 改为 `#A93A22`，对白约 6.3:1、对浅珊瑚底约 5.1:1；珊瑚色实底上用墨蓝字。
5. **触摸命中区**：只在 `pointer: coarse` 下把 `.tab`、`.btn-small`、`details summary` 扩到 44px，桌面保持紧凑，避免重排。
6. **猫头鹰描边**：造型不动，4px 描边从 `#3B3A36` 改为墨蓝 `#1E2D42`，让它像玻璃系统的一部分，而不是贴上去的贴纸。
7. **没有外部视觉稿**：本轮选定的「A · 糖果玻璃 / 1 · 晴空蓝」模拟稿就是参考，参数已写进 §5.2；不另找 Figma。
